# AI 개발 책장

그림책으로 시작해서 교과서로 깊어지는 웹북 세 권입니다. 첫 화면의 책장에서 읽을 책을 고릅니다.

바로 보기: https://notadev-iamaura.github.io/harness-book/

읽는 순서: **CS 기초 → AI 기초 → AI 하네스**

## 첫째 권 · CS 기초 · 떡볶이 주문의 여행

- 컴퓨터 과학(Computer Science) 기초: 컴퓨터, 인터넷, 서버, 데이터베이스가 일하는 원리
- **1부 그림책**: "주문하기"를 누른 뒤 0.15초 동안 주문 쪽지 '또또'가 다녀오는 길
- **2부 교과서**: 14장 + AI에게 맡길 때 점검표
- 바로 가기: https://notadev-iamaura.github.io/harness-book/#cs

## 둘째 권 · AI 기초 · 책벌레 신입사원 루미

- 생성형 AI를 다루는 기본기: 지시, 검수, 기억력, 자료 첨부, 역할 분담, 도구, 안전
- **1부 그림책**: 책은 만 권 읽었지만 가게 사정은 모르는 AI 신입사원 '루미'의 한 달
- **2부 교과서**: 9장 + 점검표
- 바로 가기: https://notadev-iamaura.github.io/harness-book/#ai

## 셋째 권 · AI 하네스 · 번개와 다섯 가지 장비

- 하네스 엔지니어링: AI 코딩 에이전트에게 일을 믿고 맡기기 위한 지시, 도구, 점검 장치의 설계
- **1부 그림책**: 똑똑하지만 덤벙대는 말 '번개'와 다섯 가지 장비 이야기
- **2부 교과서**: 14장 + 점검표
- 바로 가기: https://notadev-iamaura.github.io/harness-book/#harness

## 원작

- 첫째 권: [jedikim/cs-foundations](https://github.com/jedikim/cs-foundations) "개발의 기초" (Jedi Kim, CC0)의 1~5부(0~22장)
- 둘째 권: [아빠도, 엄마도 AI](https://textbook-web-production.up.railway.app/)의 9장
- 셋째 권: [walkinglabs/learn-harness-engineering](https://github.com/walkinglabs/learn-harness-engineering) (MIT 라이선스) 강의의 한국어 문서
