# 번개와 다섯 가지 장비

AI 코딩 에이전트에게 일을 믿고 맡기기 위한 **하네스 엔지니어링**을 두 부분으로 풀어 쓴 웹북입니다.

- **1부 그림책**: 똑똑하지만 덤벙대는 말 ‘번개’와 다섯 가지 장비 이야기 (애니메이션, 책장 넘김)
- **2부 심화편**: 움직이는 도식으로 보는 하네스 설계 교과서 14장 + 점검표

바로 보기: https://notadev-iamaura.github.io/harness-book/
