# AI 개발 책장

그림책으로 시작해서 교과서로 깊어지는 웹북 두 권입니다. 첫 화면의 책장에서 읽을 책을 고릅니다.

바로 보기: https://notadev-iamaura.github.io/harness-book/

## 첫째 권 · 떡볶이 주문의 여행 (컴퓨터 과학 기초)

- **1부 그림책**: 배달 앱의 "주문하기"를 누른 뒤 0.15초 동안, 주문 쪽지 '또또'가 다녀오는 길
- **2부 교과서**: 컴퓨터의 몸부터 배포와 관측까지 14장 + AI에게 맡길 때 점검표
- 바로 가기: https://notadev-iamaura.github.io/harness-book/#cs

## 둘째 권 · 번개와 다섯 가지 장비 (하네스 엔지니어링)

- **1부 그림책**: 똑똑하지만 덤벙대는 말 '번개'와 다섯 가지 장비 이야기
- **2부 교과서**: 움직이는 도식으로 보는 하네스 설계 14장 + 점검표
- 바로 가기: https://notadev-iamaura.github.io/harness-book/#harness

## 원작

- 첫째 권: [jedikim/cs-foundations](https://github.com/jedikim/cs-foundations) "개발의 기초" (Jedi Kim, CC0)의 1~5부(0~22장)를 다시 엮었습니다.
- 둘째 권: [walkinglabs/learn-harness-engineering](https://github.com/walkinglabs/learn-harness-engineering) (MIT 라이선스) 강의의 한국어 문서를 바탕으로 만들었습니다.

라이선스 고지는 [NOTICE.md](NOTICE.md)에 있습니다.
